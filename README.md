# Electricity Bill Calculator

## Description

This C program calculates an electricity bill based on the number of units consumed. It applies different rates for different unit ranges and adds a 20% surcharge to the calculated amount. The final bill is displayed in Rupees.

## How to Run

### Prerequisites

- A C compiler such as GCC

### Steps

1. Save the program as `electricity_bill.c`.

2. Compile the program:

   ```bash
   gcc electricity_bill.c -o electricity_bill
